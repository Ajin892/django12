# ABC School — Student Results (Django)

## Setup
1. Install Python.
2. Open a terminal in this folder.
3. Create and activate a virtual environment (recommended):
   - Windows: `python -m venv venv` then `venv\\Scripts\\activate`
   - macOS/Linux: `python3 -m venv venv` then `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`
5. Run: `python manage.py runserver`
6. Open http://127.0.0.1:8000/

The homepage lists students. Click “View Result” to see their marks.
Example URL: `/result/Ajay/`

This is a beginner demo using an in-code dictionary, not a production student-record system.
